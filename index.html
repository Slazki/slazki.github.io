About Me

Hi! I'm Fahad Majidi, a Computer Science student at UC San Diego. This portfolio contains my programming projects, explanation videos, and reflections from EDS 124BR as I learn computational thinking and programming.

Project 1 - House Drawing Program

The purpose of this program is to draw a house using a sequence of movement commands in Snap!. This video explains how each block contributes to creating the final drawing.

Project 2 - Repeats Dance Program

The purpose of this program is to make a breakdancer perform a short dance while demonstrating how repeat blocks can efficiently repeat movement, turning, and size changes in Snap!.

Project 3 - Animal Parade

This Scratch project uses repeat loops to control repeated movement and animation. The Kangaroo jumps, the Grasshopper moves and changes costumes, and the Bee uses repeated movement and turns to travel in a circle.

Reflection

I learned that programs must follow a precise sequence of instructions. I also learned that repeat blocks make code shorter and easier to understand when the same action needs to happen multiple times.
