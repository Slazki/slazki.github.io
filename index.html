About Me

Hi! I'm Fahad Majidi, a Computer Science student at UC San Diego. This portfolio contains my programming projects, explanation videos, and reflections from EDS 124BR as I learn computational thinking and programming.

Project 1 - House Drawing Program

The purpose of this program is to draw a house using a sequence of movement commands in Snap!. This video explains how each block contributes to creating the final drawing.

Project 2 - Repeats Dance Program

The purpose of this program is to make a breakdancer perform a short dance while demonstrating how repeat blocks can efficiently repeat movement, turning, and size changes in Snap!.

Project 3 - Animal Parade

This Scratch project uses repeat loops to control repeated movement and animation. The Kangaroo jumps, the Grasshopper moves and changes costumes, and the Bee uses repeated movement and turns to travel in a circle.

Project 4 - Nested Repeats

This Snap! project uses a nested repeat to make a mouse draw an octagon. The outer loop controls the turns while the inner loop repeats the movement for each side.

Project 5 - Events Program

This video explains my EDS 124BR events program and shows how event blocks are used to trigger different actions in Snap!. I also explain how changing an event would affect when and how the program runs.

Project 6 - Variables Program

This Snap! program uses the variables num_sides and side_length to draw a triangle, square, and pentagon. The video explains how changing the variable values lets the same code create different shapes and how programming variables differ from variables in algebra.

Project 7 - Conditional Loops Program

This Snap! program uses a repeat-until conditional loop to make a soccer ball move to random positions until it touches the mouse pointer. The video explains how the stopping condition controls the loop and why a conditional loop is useful when the number of repetitions is not known ahead of time.

Project 8 - If-Else Target Game

This Snap! target game uses if statements and an if-else statement to make decisions based on where the moving ball is clicked and the player's score. Clicking red subtracts points, yellow and green add points, and the program gives different feedback at the end based on the final score.

Project 9 - Nested If-Else Penguin Program

This Snap! program uses a nested if-else structure to decide what a penguin should do based on two conditions: whether it knows how to swim and whether its randomly assigned age is greater than 7. Depending on those conditions, the penguin swims, says it is too young to swim alone, or goes to build a sand castle.

Project 10 - Compound Conditionals Program

This Snap! program uses a compound conditional to decide whether it is a good day to go outside. The program randomly chooses a temperature and whether it is raining, then checks whether the temperature is above 70 and whether it is not raining before choosing the outcome.

Reflection

I learned that programs must follow a precise sequence of instructions. I also learned that repeat blocks make code shorter and easier to understand when the same action needs to happen multiple times.
